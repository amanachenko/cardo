Install

Cardo measures which ways of working with Claude Code are worth making standard, without watching any individual. This installer runs on one machine, keeps every byte inside the network, and verifies that data arrives.

Before starting

  • Docker Desktop 24 or later, running. The installer stops at the first step and reports the Docker error if it is not.
  • Docker Compose v2, included with Docker Desktop. The stack is four containers and one migration.
  • Five free loopback ports: 8124, 9001, 3001, 4319, 8089. A port in use is reported with the command that names the process.
  • 2 GB of disk and 2 GB of RAM for the stack. The data volume is kept between runs and between updates.

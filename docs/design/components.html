Requirements list

Prerequisites before a destructive or long action. One line each, no checkboxes: the installer verifies them itself and reports the first failure.

  • Docker Desktop 24 or later, running.
  • Five free loopback ports: 8124, 9001, 3001, 4319, 8089.

Rules

  • A component is taken from this file rather than redrawn.
  • A new colour or size enters the tokens and DESIGN.md first.
  • There are exactly four states: waiting, running, done, failed.
  • No cards inside cards, no rounding, no shadows, no gradients.
  • Numbers are right-aligned and tabular.
  • No screen shows one person to another.
  • A number is never shown without its source.
  • Plain words, one example for every claim.

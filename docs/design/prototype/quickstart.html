Отправления

Два пути к одному и тому же: данные с вашей машины доезжают до вашего же ClickHouse. Наружу не уходит ничего, аккаунт и хост не нужны.

Повторный запуск ничего не ломает: это починка, а не переустановка. Обновление — та же команда.

Машина

Что проверяется

Демон Docker отвечает, и версия compose не старше v2. Если демон не запущен, табло скажет это одной строкой и даст команду — без стены логов.

docker info --format '{{.ServerVersion}}'

Что проверяется

Пять портов свободны: 8124 и 9001 у ClickHouse, 3001 у Grafana, 4319 у OTLP, 8089 у хуков. Занятый порт называется вместе с процессом, который его держит.

Один раз, на этой машине

Соль псевдонимизации и два пароля генерируются здесь и пишутся в deploy/compose/.env с правами 0600. Пароли не показываются повторно. Соль: hex, 32 символа. Без неё коллектор отказывает каждой OTLP-партии, и это видно в статусе.

CARDO_SALT9f3c…7a21 · hex, 64 символа
CLICKHOUSE_PASSWORDсгенерирован · 0600
GRAFANA_PASSWORDсгенерирован · 0600
Хранитель соливы · при пилоте — служба безопасности

В одно-машинной раскладке соль лежит рядом с паролем базы. Это компромисс оценки, а не устройство: в настоящем развёртывании её держит сейф, и аналитика её не видит.

Запуск

Что запускается

ClickHouse, Grafana, коллектор и одноразовая миграция. Схема приезжает внутри образа: после обновления кода достаточно той же команды, отдельного migrate нет.

ClickHouse127.0.0.1:8124 · 9001
Grafana127.0.0.1:3001
КоллекторOTLP 4319 · хуки 8089
Миграцияодноразовая, ждёт коллектор
docker compose up -d --wait
Данные

Проверка цепи, а не «контейнер поднялся»

Табло отправляет синтетическую сессию и один хук, потом читает их обратно из ClickHouse и прогоняет запрос дэшборда. Зелёный здесь значит, что числа на дэшборде будут, а не что контейнеры живы.

cardo check --wait 30s

Что должно появиться

Одна строка из вашей собственной сессии Claude Code: время, длительность, число вызовов инструментов, версия. Ни текста промптов, ни путей, ни содержимого файлов.

Пока пусто. Сначала подключите Claude Code (следующий пункт), потом вернитесь сюда.

Люди

Один раз, без флагов на каждый запуск

Файл кладётся в настройки проекта или машины. Дальше инженер просто работает: ничего не помечает, не включает и не помнит. Двенадцать хуков, у каждого таймаут одна секунда: если коллектор недоступен, сессия продолжается.

cardo connect --once

Для команды тот же файл раскатывается через MDM, GPO или Intune, один раз и без установки агента на ноутбуки.

Читать сводки, но не людей

Grafana лидов получает отдельного пользователя базы, которому разрешены только сгруппированные вьюхи. Проверка живая: табло пытается прочитать сырую и персональную таблицу и ждёт отказа. Отказ и есть успех.

разрешеноgold_* · вьюхи с минимумом пять человек
отказаноraw_* · per-person · всё, что ниже пяти
без этогологин лида не выдаётся

Один файл, ноль установки

Тот же JSON, что и для одного человека, только с адресом коллектора в сети организации. Ни демона, ни скрипта, ни расширения. Инженер может прочитать каждую строку: это весь клиент.

deploy/managed-settings/managed-settings.json

Что организация обязана сказать

Кто держит соль. Какие настройки включены. Что данные не используются для оценки людей. Одна страница, без юридического языка, с теми же словами, что в файле настроек.

ОбъявлениеВыберите строку: Enter откроет её. Каждая проверка показывает команду, которую выполнит: табло ничего не скрывает.

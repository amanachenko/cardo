Cardo — mark candidates

One mark, three sizes. Amber is the only colour; everything else is paper on the board.

0 · current

Cardoinstallation · local only

A single amber square. Honest but anonymous: it says “status lamp”, not “Cardo”, and it is the same square the rail uses for a waiting step.

1 · two states

Cardoinstallation · local only

One filled square, one outline: done and pending. It is the rail’s own language, so the mark explains the product instead of decorating it. At 16 px the outline still reads as a square.

2 · bracket

Cardoinstallation · local only

A terminal bracket left open, with the amber square sitting inside it (variant below). Reads as “local, command-line, unfinished on purpose”. Risk: too generic for a developer tool.

3 · bracket, filled

Cardoinstallation · local only

The bracket holds the amber square: the installer holds the state. More distinctive than the plain bracket, still legible at 16 px.

4 · split flap

Cardoinstallation · local only

Two flaps of a departure board: one turned, one still to turn. Strong thematic link to the product’s history, but at 16 px the gap between flaps can fill in.

5 · progress rule

Cardoinstallation · local only

A measured rule with a coloured remainder: “this much done, this much to go”. Quiet and precise, but it reads as a progress bar and disappears at small sizes.

All six use the same two materials as the interface: paper and one amber. No gradients, no rounded corners, no letterforms borrowed from a typeface the product does not use.

# ADR-0020 — The project is called Cardo

**Status:** Accepted
**Date:** 2026-09-22
**Evidence:** Availability and collision checks performed 2026-09-22 (GitHub handles, web search for
same-category products).

## Context

The name needed to: avoid "Claude" (Anthropic trademark guidance, and it would contradict ADR-0004's
vendor neutrality); not read as a surveillance product, which rules out `watch`, `track`, `audit`,
`monitor`, `sentry`, `patrol` however good the plumbing metaphor; be easy to say out loud in a
meeting; and not collide with a product in an adjacent category.

Every short dictionary word has its bare GitHub handle taken. That is normal and mostly irrelevant here,
since ADR-0015 puts the repo under a personal account and keeps it private. The check that matters is
**category collision**.

## Decision

**Cardo.** Go module `github.com/<account>/cardo`; binary `cardo`; ClickHouse database `cardo`.

The *cardo maximus* was the main axis a Roman town was surveyed and laid out from — everything else
positioned relative to it. That maps exactly onto ADR-0001: the platform team lays down the axis, and
Cardo measures whether the town actually got built along it.

Two syllables, unambiguous pronunciation in English, no collision in any software category anyone would
confuse this with (Cardo Systems makes motorcycle headsets; Cardo AI is structured finance).

## Consequences

- No module path, table name or product string may contain "Claude" (INV, via ADR-0004).
- If a neutral GitHub org becomes warranted (ADR-0015), a suffixed form such as `cardo-dev` is available.

## Rejected alternatives and why

- **Vestigia** ("traces") — disqualified. `vestigio` on PyPI is a thin OpenTelemetry wrapper for
  agent/LLM observability using OpenInference and OTel GenAI semantic conventions. That is this
  product's exact namespace.
- **Tidemark** — the riskiest of the plausible options. Tidemark Systems sells enterprise planning
  and metrics-management analytics (501-1000 staff, now under insightsoftware). A collision in
  precisely the room Cardo would be evaluated in.
- **Signum** ("signal", and the standard a Roman unit followed) — a neat double meaning, but two
  existing developer-tools companies share the name (Signum Systems, embedded tooling, acquired by IAR;
  Signum Software, a .NET framework vendor).
- **Groma** (the Roman surveyor's instrument) — busier than hoped: Groma is a funded Boston proptech
  firm, groma.cz sells surveying software, and GROMACS is well known.
- **Gnomon** (the sundial's shadow-caster) — clean on category, and a good metaphor: the instrument does
  nothing itself, it just makes what is already happening legible. Lost on ergonomics; the silent G
  costs something on every keystroke.
- **Cairn**, **Trellis**, **Sextant**, **Plumbline**, **Almanac**, **Signalbox**, **Kiln** — all
  considered. Cairn and Trellis were the strongest English candidates; Latin was preferred for carrying
  meaning without being overused.
